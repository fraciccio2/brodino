# 📸 Cartella Foto Ricordi

Inserisci qui le fotografie della vostra amicizia per la timeline e per le sezioni speciali:

- **Fotografie Timeline (`memories`)**:
  - Formati consigliati: `.webp`, `.jpg`, `.png`
  - Risoluzione consigliata: 1200x800px o simile (proporzioni 4:3 o 16:9)
  - Esempio di percorso in `src/data/birthday.ts`: `image: "/photos/foto-2018.jpg"`

- **Fotografia Finale (`finalMessage.finalPhoto`)**:
  - La foto più significativa di voi due per i titoli di coda finali.
  - Esempio: `/photos/final.jpg`

- **Fotografia Segreta Easter Egg (`easterEgg.image`)**:
  - La foto "imbarazzante" o segreta sbloccata tramite il Konami Code (`↑ ↑ ↓ ↓ ← → ← → B A`).
  - Predefinita: `/photos/easter-egg.jpg` con didascalia configurabile.
