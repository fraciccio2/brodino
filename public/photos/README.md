# 📸 Cartella Foto Ricordi

Inserisci qui le fotografie della vostra amicizia per la timeline:
- Formati consigliati: `.webp`, `.jpg`, `.png`
- Risoluzione consigliata: 1200x800px o simile (proporzioni 4:3 o 16:9)

Una volta inserite le foto, aggiorna i percorsi corrispondenti nel file:
`src/data/birthday.ts` (nella sezione `memories`).
Ad esempio:
```typescript
image: "/photos/la-nostra-foto-2018.jpg"
```
